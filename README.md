# 🌍 Phanthom Global Travel Website

> ✈️ *Explore the world through design*  
> A visually engaging and responsive travel website built to inspire adventure and global exploration.

---

## 🌟 About the Project
**Phanthom Global Travel Website** is a front-end web project designed to showcase travel destinations with an elegant UI and smooth user experience.  
The project focuses on clean design, responsiveness, and simplicity — perfect for travel agencies, portfolio demos, or academic projects.

---

## 🎯 Project Goals
- Create an attractive travel-themed website  
- Practice modern **HTML, CSS, and JavaScript**  
- Deliver a responsive and user-friendly interface  
- Present destinations in a visually appealing way  

---

## ✨ Key Features
- 🌐 Travel-focused landing page  
- 🖼️ Eye-catching images & layouts  
- 📱 Fully responsive (mobile, tablet, desktop)  
- ⚡ Lightweight & fast loading  
- 🎨 Clean and modern UI design  

---

## 🛠️ Built With
- **HTML5** – Page structure  
- **CSS3** – Styling & responsiveness  
- **JavaScript** – Interactivity
